# Context

## Background
This is a new project to create a minimal "Hello World" C# console application. This serves as a starting point or template for future .NET development.

## Technology Stack
- Language: C#
- Framework: .NET (6+ or 8)
- Project Type: Console Application
- Build System: dotnet CLI

## Assumptions
- .NET SDK is installed on the development machine
- The project will be created using `dotnet new console`
- No existing project structure or codebase to integrate with
- This is a greenfield project

## Risks
- Minimal risk due to simplicity of the task
- Potential risk: .NET SDK version mismatch if not installed
