# Scope

## Objective
Create a simple "Hello World" C# console application.

## Deliverables
- A single C# console application project
- Program prints "Hello, World!" to standard output
- Standard .NET project structure

## Out of Scope
- No external dependencies or NuGet packages
- No unit tests
- No CI/CD configuration
- No deployment
- No complex architecture or design patterns
- No user input handling
- No error handling beyond default

## Constraints
- Must use .NET (modern .NET, e.g., .NET 6+ or .NET 8)
- Must be a console application
- Must compile and run without errors
- Must be a single project (no solution file needed)
