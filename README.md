# Digital-Worker-Demo
Repo connected to Digital Worker Demo agent for demos, playing, learning and experimentation

## How to Use

This repository is used for demos and experimentation with the Digital Worker agent. Here's how to use it:

1. **Create a Trello card** — Describe your task on a Trello card in the connected board. The task description should clearly state what you want the Digital Worker to do (e.g., add documentation, modify code, create a new feature).

2. **Assign the card** — Assign the card to the Digital Worker agent. The agent will pick it up, read the description and comments, and execute the task directly in this repository.

3. **Review the work** — The agent will commit changes to a feature branch and open a pull request automatically. Review the PR for correctness.

4. **Provide feedback** — Add comments on the Trello card or PR to request adjustments. The agent can iterate based on your feedback.

5. **Merge** — Once satisfied, merge the pull request to apply the changes.
